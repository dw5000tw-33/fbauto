# Facebook Alpha 2.1：本機驗收版

只調整 Alpha 與測試檔。根目錄正式 bookmarklet、panel-bootstrap、v1.9／v1.8／v1.7 沒有修改。未發布到 GitHub Pages，未操作真實 Facebook 貼文，也未修改 Notion。

## 載入順序

Alpha 書籤 → alpha/panel-bootstrap.html → panel-v2.0-alpha.js → facebook-style-v2.0-alpha.js → facebook-patrol-v2.1-alpha.js → cleanup-runner.js → group-cleanup-v2.0-alpha.js → listing-store-v2.1-alpha.js → listing-center-v2.1-alpha.js。

每個檔案15秒載入上限。載入器保留 nonce、來源及視窗檢查。舊 facebook-interaction-v2.0-alpha.js 不再載入，避免兩套 tracker 事件同時控制畫面。

## 已完成

- 保留藍色外觀、固定可視高度、內部捲動、最小化還原、所有功能共用「顯示功能選單」。
- 社團清單可本機保存；巡禮使用已勾選社團、關鍵字、逐則候選、每則愛心／填留言／完成／略過。
- 防連按、取消工作、關閉停止、授權失效停止、換團阻擋舊候選。鍵盤輸入框中不攔截互動快捷鍵。
- 原生愛心只在本則找到唯一明確選項時點擊，不以讚替代；無法辨識時提示手動操作。
- 留言只填目前貼文中唯一可辨識的原生框，不找其他貼文框、不覆蓋不同草稿、不點送出。
- 案件主檔＋照片＋刊登紀錄＋異動紀錄，儲存在 IndexedDB。照片以 Blob 保存，可調整排序與封面、匯出及在空資料庫還原。
- 委託編號優先去重；沒有編號時以明確地址／樓層判斷。行政區只從完整地址拆分，缺少時空白。資料庫唯一索引阻擋相同識別碼並發新增。
- 卡片顯示照片、編號、價格與單位、案件狀態、最近刊登時間、Marketplace與社團狀態。每頁最多30案。
- Marketplace／各社團刊登分開建紀錄，不複製案件；版本不一致顯示待同步。紀錄可保存預定時間、實際刊登時間、網址、待審／失敗／結果不明等狀態。
- 到時提醒只在本頁開啟時工作，不自動發文。
- 本機永久刪除須逐筆勾選＋列名最後確認，完全不連動刪Facebook。Facebook刊登刪除需在該筆紀錄勾選、確認，再交給使用者在原生頁面最後執行。
- 舊社團自有貼文批次清理改為只預覽，避免繞過逐筆確認。

## 使用方式與限制

1. 在社團整理載入或掃描清單並勾選，再到社團巡禮建立進度。跨社團採原生導航；整頁載入會移除書籤面板，因此到新社團後重新點 Alpha 書籤並驗證。進度與關鍵字會恢復，不保存授權。
2. 物件刊登中心先建案，加入照片與文案，再為 Marketplace 或已勾選社團建立紀錄。開啟原生頁面後，重新開 Alpha 並選同一案件。
3. 「準備填入」只接受當前原生表單內唯一明確欄位，無法辨識就停止。照片目前提供下載，由使用者加入原生上傳框；不承諾自動附件上傳。
4. 發布、儲存修改、下架、Facebook最終刪除都由使用者操作。已發布／已下架／已刪除標記明示為人工確認，必須有Facebook網址，不以按鈕點擊推定成功。實際發布時間由使用者填入，不猜測。
5. 不會匯入歷史Facebook刊登或自動同步其狀態。已存在的刊登可透過案件紀錄手動綁定網址。此版沒有雲端跨裝置同步或無人排程，也未連結Notion。
6. 資料按瀏覽器及網站來源隔離；www.facebook.com、其他Facebook子網域與localhost的資料彼此不同。請匯出備份，還原僅允許空資料庫。
7. Facebook實際反應選單、發文框、Marketplace欄位、圖片上傳及待審狀態仍需登入後現場驗收；本機通過不表示已驗證線上介面。

## 驗收

執行 `node test/check-syntax.js` 及 `node --test test/*.test.js`。

執行 `node test/serve-preview.js` 後開啟 http://127.0.0.1:8765/test/preview.html。此頁用模擬驗證，不連外部服務；可加入3筆測試案件與示範圖，重新載入後檢查保存。測試資料只在localhost來源，與Facebook真實資料隔離。

自動測試涵蓋完整模組組合、授權、停止／關閉、留言範圍、不送出／不覆蓋、愛心不按讚、防重入、進度恢復、案件去重、行政區、版本待同步、通路分離、逐筆勾選與刪除取消、備份還原取消及不覆蓋。

本機瀏覽器已核對3案／3圖重新載入保存、編輯儲存、最小化還原、內部捲動，以及1024×768和1280×1080可視範圍。此為 Alpha 2.1 部署版本；Facebook 原生介面仍待現場驗收。
