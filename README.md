# 33 Facebook 房仲刊登助手

把房仲案件、照片、Facebook Marketplace 刊登與社團貼文紀錄整理在同一個工作台。

> 目前版本：v2.2 Alpha  
> 適用環境：Windows 11／Chrome／Facebook 網頁版  
> 最後的「發布、修改、下架、刪除」仍由使用者在 Facebook 原生介面確認。

## 主要功能

- **物件刊登中心**：保存委託編號、標題、價格、地址、格局、坪數、文案及最多 20 張照片。
- **Marketplace 上架準備**：出售案件使用一般「出售商品」；出租案件使用 Facebook 房屋租賃表單，協助準備對應文字、價格、地址與照片。
- **社團清單整理**：掃描「你的社團」，在本機勾選並保存常用社團。
- **社團刊登紀錄**：每個案件分別記錄 Marketplace 與各社團的刊登狀態、網址及時間。
- **社團巡邏**：依關鍵字逐則檢查互動；不會自動送出留言。
- **舊貼文整理**：依作者與截止日期尋找候選貼文，預設僅預覽；刪除前必須逐筆確認。
- **本機備份**：案件資料儲存在瀏覽器 IndexedDB，可匯出及還原 JSON 備份。

## 快速開始

1. 開啟 [v2.2 Alpha 測試入口](https://dw5000tw-33.github.io/fbauto/bookmarklet-test.html)。
2. 將「Facebook 刊登助手」按鈕拖到瀏覽器書籤列。
3. 登入 Facebook 後點擊該書籤。
4. 輸入從 33 Works LINE 取得的通行碼。
5. 先在「物件刊登中心」建立案件，再建立 Marketplace 紀錄。
6. 點「前往 Marketplace 建立刊登」，於新分頁重新啟動工具。
7. 選回同一案件，按「準備 Marketplace 文字與照片」。
8. 核對分類、刊登類型、地點、價格、照片及全部內容後，由你手動發布。

## 安全原則

這個工具採人機協作設計：

- 不會在背景無人值守大量發布。
- 不會自動按下 Facebook 的最終「發布」按鈕。
- 不會把按過工具按鈕視為發布成功。
- 不會自動刪除 Facebook 貼文或 Marketplace 商品。
- 原生頁面已有不同草稿時，不會直接覆蓋。
- 無法唯一辨識 Facebook 欄位時會停止，改由使用者手動完成。
- 舊貼文整理預設為僅預覽，作者、日期或網址無法確認時會略過。

## 資料與隱私

案件、照片、社團清單及刊登紀錄主要保存在使用者自己的瀏覽器。跨裝置不會自動同步，請定期使用「匯出備份」。通行碼驗證由 33 Works 授權服務處理；Facebook 帳號密碼不會交給本工具保存。

## 已知限制

- Facebook 可能隨時調整 Marketplace 與社團頁面的介面，欄位辨識需要持續驗收。
- Facebook 台灣目前的房屋專用表單僅適合租賃；房屋出售維持一般「出售商品」流程。
- Marketplace 分類、刊登類型、地點及 Facebook 要求的其他欄位仍需人工核對。
- 瀏覽器不允許或無法唯一辨識照片欄位時，請下載本案照片後手動加入。
- 此版本沒有雲端跨裝置同步，也不是無人排程機器人。
