# 33 Marketplace 自動上架助手 v2.6.0

這是 Chrome Manifest V3 擴充功能原型，將房屋商品、文案、照片、固定社團與上架時間儲存在擴充功能中，時間到後依序開啟 Facebook Marketplace 一般「出售商品」頁面。

## 安裝測試

1. Chrome 開啟 `chrome://extensions/`。
2. 開啟右上角「開發人員模式」。
3. 選擇「載入未封裝項目」。
4. 選擇本資料夾。
5. 登入 Facebook，點擊工具列中的「33 Marketplace 自動上架助手」。

## 使用方式

1. 點「選擇案件資料夾」，資料夾內可放一份 `.txt`／`.md` 文稿、最多 10 張照片及社團用影片。
2. 工具會使用文稿第一個非空白行作為標題，並嘗試從「1598萬」這類文字換算完整售價。
3. 以照片縮圖確認封面與順序，需要時可前後移動或移除。
4. 確認標題、售價、文案與固定選項。
5. 可在 Facebook「在更多地方上架」頁面先勾選常用社團，再由面板讀取並儲存社團組合（最多 20 個）。
6. 使用快捷按鈕設定台灣上架時間，並選擇一般或慢速電腦模式。
7. 設定案件之間的等待分鐘數；同時到期的案件只會逐件執行。
8. 若要讓工具直接完成發布，逐筆勾選「到時間允許助手直接按下發布」。
9. 「背景執行」預設開啟，排程到點會在背景分頁操作；若需觀察每一步可取消勾選。
10. 儲存排程；面板最多同時保留 10 個等待或執行中的案件，可修改、取消或立即執行。
11. 可使用「匯出社團」備份所有固定社團組合，安裝新版後再用「匯入社團」恢復；同名組合會更新。
12. 只有確認為「已發布」的案件才會顯示「開啟剛上架商品」，直接開啟該次保存的 Marketplace 網址，供刪除流程驗證使用；停在確認頁的草稿不會成為刪除目標。
13. v2.5.0 新增「刪除剛上架商品」單筆測試流程：只依保存的 Marketplace 刊登 ID 尋找商品，選擇「否，未售出」並確認商品從賣家清單消失；找不到確切 ID 時停止，不以同名標題替代。
14. v2.5.1 修正社團備份匯入後的選取與數量提示，並新增「讀取已發布社團」：可從「你的商品」中已打開的上架地點清單建立固定社團組合。
15. v2.5.2 讀取已發布社團時會自動捲動完整清單，避免 Facebook 只載入目前畫面可見的上半段社團。
16. v2.5.3 人工確認後改由「確認完成並發布」接續原分頁，並辨識 Facebook「審閱中」狀態，避免誤判失敗後重複刊登。
17. v2.5.4 新增背景執行、跨頁發布結果追蹤、重複刊登辨識、發布逾時保護，以及「停止並釋放隊列」與人工確認未上架後重試。
18. v2.5.5 加強 Facebook 下拉選單的文字正規化與三次重試；若欄位仍未回寫，保留原分頁並轉為人工確認，不再直接判定整件失敗。
19. v2.5.6 為「結果待確認」新增重新檢查目前 Facebook 頁面、人工確認仍在審閱與人工確認已上架，讓關機或跨頁後仍可同步真實刊登狀態。
20. v2.6.0 將上架與刪除拆成獨立流程：按下 Facebook 發布後即記為「已送出 Facebook」並釋放下一案件，不等待平台審閱；新增刪除排程中心，支援完整標題、包含全部關鍵字或包含任一關鍵字，可先預覽清單或明確授權到時直接逐筆刪除。

## v2.6 刪除排程中心

1. 刪除流程不依賴上架時取得的 Marketplace ID，也不要求保留原上架排程。
2. 「完整標題符合」用於單一案件；正規化空白與大小寫後，商品標題必須與輸入文字完全相同。
3. 「包含全部關鍵字」要求商品卡同時出現所有關鍵字，例如「南屯」與「平車」。
4. 「包含任一關鍵字」只要符合其中一個便列入，適合批次下架不同區域或不同產品。
5. 預設只掃描並產生刪除清單；使用者確認清單後才逐筆刪除。
6. 只有明確勾選「到時間直接刪除所有符合商品」，才會在排程時間自動刪除掃描到的全部項目。
7. 刪除原因固定選擇「否，未售出」；單筆失敗會記錄原因並繼續處理下一筆。

## 執行條件

- Windows 必須開機且未休眠。
- Chrome 必須保持執行，Facebook 登入狀態有效。
- Facebook 若要求驗證或介面改版，工具會停止並將案件標示為失敗，不會無限重試。
- 固定社團使用完整名稱比對；必要社團未找到時會停止，不會只發布 Marketplace 後假裝成功。
- Marketplace 一般出售商品頁目前使用照片；資料夾中的影片只會計數，不會加入此刊登。

## 狀態

- `已排程`：等待執行時間。
- `執行中`：已開啟 Marketplace 並準備欄位。
- `已按發布，正在確認結果`：Facebook 已收到按鈕操作，背景服務正在跨頁追蹤結果。
- `排隊中`：另一案件正在執行，等待設定的案件間隔。
- `已發布`：偵測到 Marketplace 商品網址。
- `已送出，Facebook 審閱中`：Facebook 已建立刊登但尚在審閱。
- `結果待確認`：無法精確證明成功或失敗；後續隊列已釋放，需人工查看「你的商品」。
- `已填入，等待確認`：沒有勾選自動發布。
- `失敗`：Facebook 驗證、欄位改版或其他錯誤，等待人工接手。
- `已取消`：排程保留在清單中，但不會自動執行。

正式使用前，請先以「測試－請勿發布」案件驗收完整流程。
