# 33 Marketplace 自動上架助手 v2.3

這是 Chrome Manifest V3 擴充功能原型，將房屋商品、文案、照片與上架時間儲存在擴充功能中，時間到後自動開啟 Facebook Marketplace 一般「出售商品」頁面。

## 安裝測試

1. Chrome 開啟 `chrome://extensions/`。
2. 開啟右上角「開發人員模式」。
3. 選擇「載入未封裝項目」。
4. 選擇本資料夾。
5. 登入 Facebook，點擊工具列中的「33 Marketplace 自動上架助手」。

## 使用方式

1. 點「選擇案件資料夾」，資料夾內可放一份 `.txt`／`.md` 文稿、最多 10 張照片及社團用影片。
2. 工具會使用文稿第一個非空白行作為標題，並嘗試從「1598萬」這類文字換算完整售價。
3. 確認標題、售價、文案與固定選項。
4. 設定台灣上架時間。
5. 若要讓工具直接完成發布，逐筆勾選「到時間允許助手直接按下發布」。
6. 儲存排程。

## 執行條件

- Windows 必須開機且未休眠。
- Chrome 必須保持執行，Facebook 登入狀態有效。
- Facebook 若要求驗證或介面改版，工具會停止並將案件標示為失敗，不會無限重試。
- Marketplace 一般出售商品頁目前使用照片；資料夾中的影片只會計數，不會加入此刊登。

## 狀態

- `已排程`：等待執行時間。
- `執行中`：已開啟 Marketplace 並準備欄位。
- `已發布`：偵測到 Marketplace 商品網址。
- `已填入，等待確認`：沒有勾選自動發布。
- `失敗`：Facebook 驗證、欄位改版或其他錯誤，等待人工接手。

正式使用前，請先以「測試－請勿發布」案件驗收完整流程。
